# LordVersA Homebrew tap

```sh
brew install --cask lordversa/tap/v2mac
```

Installs [V2Mac](https://github.com/LordVersA/v2mac), a menu bar client for Xray-core (macOS 26 or later, Apple Silicon). The app is not notarized; the cask removes the quarantine flag so it opens without the Gatekeeper prompt.

Update with `brew upgrade --cask v2mac`.
